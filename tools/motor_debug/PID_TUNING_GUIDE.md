# RMD 电机 PID 试凑法整定指南

> 适用于瓴控科技 RMD 系列电机，三环串级 PID 控制结构
> 配合 `rmd_debug.py` 工具使用

---

## 一、理解三环串级结构

RMD 电机内部是经典的三环串级控制，**从内到外**依次为：

```
┌─────────────────────────────────────────────────────────────┐
│  位置指令 ──→ [角度环 PID] ──→ 速度指令                        │
│                                  │                          │
│               速度指令 ──→ [速度环 PID] ──→ 电流指令            │
│                                             │               │
│                          电流指令 ──→ [电流环 PID] ──→ PWM     │
│                                                      │      │
│                                                    电机      │
└─────────────────────────────────────────────────────────────┘
```

### 核心原则：从内环到外环，逐环整定

| 顺序 | 环路 | ParamID | 功能 | 带宽要求 |
|------|------|---------|------|---------|
| 1 | 电流环 (current) | 0x0C | 控制电机电流/力矩 | 最快 (kHz级) |
| 2 | 速度环 (speed) | 0x0B | 控制电机转速 | 中等 (百Hz级) |
| 3 | 角度环 (angle) | 0x0A | 控制电机位置 | 最慢 (十Hz级) |

**为什么从内到外？** 外环的输出是内环的输入。如果内环没调好，外环无论怎么调都不会好。就像盖房子必须先打地基。

## 二、调试前准备

### 2.1 安全检查清单

- [ ] 机械臂处于安全位置，周围无人无障碍物
- [ ] 减速机/传动机构无异常间隙
- [ ] 急停按钮随手可及
- [ ] CAN 通讯正常 (`candump can0` 能看到帧)
- [ ] 了解电机的额定参数（额定电流、额定转速、减速比）

### 2.2 读取出厂默认值并记录

```bash
# 读取并记录所有出厂 PID，这是你的回退基准！
python3 rmd_debug.py --can can0 --id 1 read-pid
```

**务必记录下来！** 建议用表格保存：

| 电机ID | 环路 | Kp | Ki | Kd |
|--------|------|----|----|-----|
| 1 | angle | ? | ? | ? |
| 1 | speed | ? | ? | ? |

### 2.3 准备观测手段

调 PID 必须能**看到电机的实时响应**。可选方案：

1. **rmd_debug.py status 轮询**：最简单，但采样率低
2. **candump + 0x9C 状态帧**：用另一个终端 `candump can0` 观察回复帧
3. **ros2 topic echo**：如果 ros2_control 在运行，直接看 joint_states
4. **PlotJuggler / rqt_plot**：实时画曲线，最直观（推荐）

## 三、试凑法整定步骤

### 第一步：电流环整定（通常不需要动）

> 电流环出厂已调好，且带宽最高（开关频率级），一般**不建议修改**。
> 除非你遇到以下情况才需要调：
> - 电机异响（啸叫、高频振动）
> - 发热异常
> - 更换了电机型号

如果确实需要调，方法：

```bash
# 1. 先读出来
python3 rmd_debug.py --can can0 --id 1 read-pid

# 2. 用转矩闭环命令 (0xA1) 给一个小电流阶跃
#    观察电流响应是否快速达到目标且无明显振荡

# 3. 如果振荡：降低 current Kp
# 4. 如果响应慢：增大 current Kp
# 5. current Ki 用于消除稳态误差，一般不需要太大
# 6. current Kd 通常设为 0
```

**结论：大多数情况跳过此步，直接调速度环。**

---

### 第二步：速度环整定

#### 准备

```bash
# 确保电机处于运行状态
python3 rmd_debug.py --can can0 --id 1 motor run
```

#### 步骤 2.1：清零 Ki 和 Kd，只留 Kp

```bash
# 先读当前值
python3 rmd_debug.py --can can0 --id 1 read-pid

# 将速度环 Ki=0, Kd=0, Kp 设为出厂值的一半
python3 rmd_debug.py --can can0 --id 1 write-pid --loop speed --kp <出厂Kp/2> --ki 0 --kd 0
```

#### 步骤 2.2：逐步增大 Kp

用速度闭环命令给一个速度阶跃（比如 100 dps），观察实际转速响应：

```
Kp 太小:                    Kp 合适:                    Kp 太大:
速度                        速度                        速度
  ........──── 目标           ┌──────── 目标              ╭─╮
 ╱                           │                          │  │  ╭─╮
╱                            │                          │  ╰──╯  ╰── 目标
                              │                          │
──────── 时间               ──────── 时间               ──────── 时间
响应慢，有稳态误差           快速到达，轻微过冲            持续振荡
```

**调整策略：**
- 从小到大增加 Kp（每次增加 20%~50%）
- 直到出现**轻微过冲但能快速收敛**
- 如果出现持续振荡 → 回退到上一个值的 60%~70%

#### 步骤 2.3：加入 Ki 消除稳态误差

```bash
# Ki 从小值开始，建议从 Kp 的 1/10 ~ 1/5 开始
python3 rmd_debug.py --can can0 --id 1 write-pid --loop speed --kp <调好的Kp> --ki <Kp/10> --kd 0
```

**Ki 的效果：**
- Ki = 0：可能有稳态误差（速度始终差一点到不了目标）
- Ki 合适：稳态误差消除，过冲不明显增大
- Ki 太大：低频振荡（速度在目标值附近来回摆动，频率比 Kp 振荡低）

**调整策略：**
- 逐步增大 Ki（每次增加 50%）
- 直到稳态误差消除
- 如果出现低频振荡 → 减小 Ki

#### 步骤 2.4：Kd（可选）

速度环的 Kd 通常**设为 0 或很小的值**。原因：
- 速度信号本身噪声较大
- Kd 对噪声敏感，容易引入高频抖动
- 速度环已经有电流环作为内环，响应本身就够快

如果确实需要（比如希望抑制速度过冲）：
```bash
# Kd 从很小的值开始，建议 Kp 的 1/100 ~ 1/50
python3 rmd_debug.py --can can0 --id 1 write-pid --loop speed --kp <Kp> --ki <Ki> --kd <很小值>
```

#### 速度环验收标准

- [ ] 阶跃响应上升时间合理（不太慢）
- [ ] 过冲量 < 15%（轻微过冲可接受）
- [ ] 无持续振荡
- [ ] 稳态误差接近 0
- [ ] 电机无异常噪音

---

### 第三步：角度环整定（你的顿挫问题重点在这里）

> **你描述的"减速太快导致反向扭矩太大"，核心原因大概率是角度环 Kp 过大。**
>
> 角度环 Kp 太大 → 接近目标位置时仍输出很大的速度指令 → 速度环忠实执行 →
> 到达目标后速度不为零 → 产生反向纠正力矩 → 顿挫

#### 步骤 3.1：清零 Ki 和 Kd，只留 Kp

```bash
# 读取当前角度环参数
python3 rmd_debug.py --can can0 --id 1 read-pid

# 只保留 Kp，Ki=0, Kd=0
# Kp 先设为出厂值的 50%
python3 rmd_debug.py --can can0 --id 1 write-pid --loop angle --kp <出厂Kp/2> --ki 0 --kd 0
```

#### 步骤 3.2：用 0xA4 位置命令测试

通过 ros2_control 或直接发 CAN 帧给一个位置阶跃，观察：

```
Kp 太大（你的当前问题）:          Kp 合适:
位置                              位置
  ╭─╮                              ┌────────── 目标
  │  │  ← 过冲后急刹               │
  │  ╰── 目标                      │
  │                                │
──────── 时间                    ──────── 时间
到位快但有顿挫/过冲                平滑到位，无振荡

Kp 太小:
位置
  .........────── 目标
 ╱   ← 响应很慢
╱
──────── 时间
到位慢，感觉"肉"
```

**调整策略：**

```
1. 从出厂值的 50% 开始
2. 给一个位置阶跃（比如从当前位置运动 30°）
3. 观察运动过程：
   - 到位平滑，无顿挫 → 尝试增大 10%，重复测试
   - 到位有轻微过冲但可接受 → 当前值 OK
   - 到位有明显过冲/顿挫 → 减小 20%
   - 到位太慢 → 增大 20%
4. 找到"刚好不顿挫"的临界值，然后取 80% 作为最终值
```

#### 步骤 3.3：加入 Kd 抑制过冲（角度环的关键）

> **对角度环来说，Kd 是抑制顿挫的核心参数！**
>
> Kd 的物理意义：提供与速度成正比的阻尼力。接近目标时如果速度还很大，
> Kd 会产生制动作用，让电机提前减速，而不是到了才急刹。

```bash
# Kd 建议从 Kp 的 1/5 ~ 1/2 开始
python3 rmd_debug.py --can can0 --id 1 write-pid --loop angle --kp <调好的Kp> --ki 0 --kd <Kp/5>
```

**Kd 的效果：**

```
无 Kd:                           有合适 Kd:
位置                              位置
  ╭─╮                              ┌────────── 目标
  │  ╰── 目标                      │
  │                                │  ← 提前减速，平滑到位
──────── 时间                    ──────── 时间

Kd 太大:
位置
  ..........────── 目标
 ╱    ← 过度阻尼，响应变慢
╱
──────── 时间
```

**调整策略：**
- 从小值开始逐步增大
- 每次增加 20%~30%
- 直到过冲/顿挫消失
- 如果响应变得太慢 → 稍微减小 Kd，同时可以适当增大 Kp

#### 步骤 3.4：加入 Ki（可选，谨慎）

角度环的 Ki **通常设得很小或为 0**。原因：
- 位置控制本身就有积分效应（位置误差不消除就一直存在）
- Ki 过大容易导致积分饱和 → 到位后继续"冲"过去 → 振荡

只有在以下情况才加 Ki：
- 存在恒定外力矩（如重力导致手臂下垂）
- Kp + Kd 调好后仍有小的稳态位置误差

```bash
# Ki 从非常小的值开始，Kp 的 1/50 ~ 1/20
python3 rmd_debug.py --can can0 --id 1 write-pid --loop angle --kp <Kp> --ki <Kp/50> --kd <Kd>
```

#### 角度环验收标准

- [ ] 位置阶跃响应平滑，无顿挫
- [ ] 过冲量 < 5%（位置控制要求更严格）
- [ ] 到位后无振荡
- [ ] 稳态位置误差在可接受范围内
- [ ] 不同运动幅度（大角度和小角度）都表现良好
- [ ] 不同负载状态下都稳定

## 四、针对你的顿挫问题的推荐调试流程

### 快速排查路径

```
第1步: 读出厂PID → 记录备份
          │
第2步: 角度环 Kp 减半，Ki=0，Kd=0
          │
          ├─ 顿挫消失 → Kp 原值过大，在当前值基础上微调
          │
          └─ 顿挫仍在 → 不是角度环 Kp 的问题，检查速度环
                │
第3步: 速度环 Kp 减半
                │
                ├─ 顿挫消失 → 速度环 Kp 过大
                │
                └─ 顿挫仍在 → 可能是机械问题或通讯问题
```

### 推荐的参数调整顺序

```bash
# 1. 读出厂值
python3 rmd_debug.py --can can0 --id 1 read-pid

# 2. 假设出厂角度环 Kp=200, Ki=50, Kd=0
#    先把 Ki 去掉，Kp 减半
python3 rmd_debug.py --can can0 --id 1 write-pid --loop angle --kp 100 --ki 0 --kd 0

# 3. 测试运动，观察效果

# 4. 如果好很多，加入 Kd 进一步优化
python3 rmd_debug.py --can can0 --id 1 write-pid --loop angle --kp 100 --ki 0 --kd 30

# 5. 微调 Kp 和 Kd，找到最佳平衡点

# 6. 最后考虑是否需要加一点 Ki
python3 rmd_debug.py --can can0 --id 1 write-pid --loop angle --kp 100 --ki 5 --kd 30
```

## 五、调试技巧和注意事项

### 5.1 黄金法则

1. **一次只改一个参数**。改了两个参数效果变差，你不知道是哪个的问题。
2. **每次改动幅度不超过 50%**。PID 对参数敏感，大幅改动可能直接从稳定变振荡。
3. **改完必须测试**。不要凭感觉连续改好几个参数再测。
4. **记录每次参数和效果**。建议用表格：

| 序号 | Kp | Ki | Kd | 现象 |
|------|----|----|-----|------|
| 1 | 200 | 50 | 0 | 到位顿挫明显 |
| 2 | 100 | 0 | 0 | 顿挫减轻，到位慢 |
| 3 | 100 | 0 | 30 | 平滑到位 |
| ... | | | | |

### 5.2 常见现象与对策速查表

| 现象 | 最可能原因 | 调整方向 |
|------|----------|---------|
| 到位时顿挫/冲击 | 角度环 Kp 太大 | 降低 angle Kp，增加 angle Kd |
| 到位后来回振荡（低频） | 角度环 Ki 太大 | 降低 angle Ki |
| 到位后来回振荡（高频） | 速度环 Kp 太大 | 降低 speed Kp |
| 运动中电机啸叫 | 电流环 Kp 太大 | 降低 current Kp |
| 响应太慢，像"拖泥带水" | Kp 太小 | 增大对应环 Kp |
| 到不了目标位置（差一点） | Ki 不够 | 增大对应环 Ki |
| 小幅运动正常，大幅运动过冲 | 速度环 Kp 太大或速度限制太高 | 降低 speed Kp 或 maxSpeed |
| 大幅运动正常，小幅运动抖动 | 角度环 Kp 太大 + 编码器分辨率限制 | 降低 angle Kp |
| 匀速正常，加减速顿挫 | 角度环 Kd 太小 | 增大 angle Kd |
| 空载好，带载振荡 | 各环增益太高 | 整体降低 Kp |

### 5.3 不同关节可能需要不同参数

你的机器人有 7 个 RMD 关节（turn + left/right joint2/3/4），它们的负载不同：

| 关节 | 特点 | PID 倾向 |
|------|------|---------|
| turn | 底盘转向，惯量最大 | Kp 偏小，Kd 偏大 |
| joint2 | 肩关节，承受整条臂重量 | 需要较大 Ki（抗重力） |
| joint3 | 肘关节，中等负载 | 均衡参数 |
| joint4 | 腕关节，负载最小 | Kp 可以偏大，响应快 |

**每个关节单独整定**，不要所有关节用同一套参数。

### 5.4 写入 RAM vs ROM

```bash
# 写入 RAM（掉电丢失）—— 调试阶段始终用这个
python3 rmd_debug.py --can can0 --id 1 write-pid --loop angle --kp 100 --ki 0 --kd 30

# 调好后如果要固化到 ROM，需要修改脚本使用不同的命令
# 或者通过上位机软件写入 ROM
# ⚠️ ROM 写入次数有限（Flash 寿命），不要频繁写入！
```

### 5.5 调试安全技巧

1. **先空载调，再带载调**。拆掉末端负载先调，确认参数范围合理后再装回负载微调。

2. **从慢到快测试**。先用小角度（5°~10°）阶跃测试，确认稳定后再测大角度。

3. **准备"急救"命令**。如果电机剧烈振荡，立即执行：
   ```bash
   python3 rmd_debug.py --can can0 --id 1 motor stop
   ```

4. **恢复出厂值**。如果调乱了，写回之前记录的出厂值：
   ```bash
   python3 rmd_debug.py --can can0 --id 1 write-pid --loop angle --kp <出厂Kp> --ki <出厂Ki> --kd <出厂Kd>
   ```

5. **注意温度**。反复调试会让电机发热，定期检查温度：
   ```bash
   python3 rmd_debug.py --can can0 --id 1 status
   ```
   温度 > 70°C 应暂停调试，让电机冷却。

### 5.6 Kp / Ki / Kd 的直觉理解

```
Kp（比例）= 弹簧
  误差越大，输出力越大。
  Kp 大 → 硬弹簧 → 响应快但容易振荡
  Kp 小 → 软弹簧 → 响应慢但稳定

Ki（积分）= 耐心
  误差持续存在，输出力慢慢累积。
  Ki 大 → 急性子 → 快速消除误差但容易冲过头
  Ki 小 → 慢性子 → 稳态精度好但消除误差慢

Kd（微分）= 阻尼器/减震器
  误差变化越快，阻力越大。
  Kd 大 → 硬减震 → 抑制振荡但响应变慢
  Kd 小 → 软减震 → 响应快但容易过冲
```

### 5.7 数值范围参考

瓴控 RMD 电机的 PID 参数是 uint16_t（0~65535），但**实际有效范围远小于此**。
以下是典型数量级（仅供参考，具体看你的电机型号）：

| 环路 | Kp 典型范围 | Ki 典型范围 | Kd 典型范围 |
|------|-----------|-----------|-----------|
| 角度环 | 30 ~ 300 | 0 ~ 50 | 0 ~ 100 |
| 速度环 | 20 ~ 200 | 5 ~ 100 | 0 ~ 30 |
| 电流环 | 50 ~ 500 | 10 ~ 200 | 0 (通常不用) |

> ⚠️ 以上仅为参考，必须以你读出的出厂值为基准来调整。
