# RMD 电机 PID 整定上位机 使用说明

> `rmd_tuner.py` — 基于 PyQt5 的集成化 GUI 工具
> 适用于瓴控科技 RMD 系列电机的三环 PID 参数整定

---

## 一、安装与启动

### 1.1 依赖安装

```bash
pip install PyQt5 matplotlib numpy
```

### 1.2 CAN 接口准备

```bash
# 启动 CAN 接口 (波特率根据实际设置)
sudo ip link set can0 up type can bitrate 1000000

# 验证接口已启动
ip link show can0
# 应看到 state UP

# 可选: 用 candump 验证总线上有帧
candump can0
```

### 1.3 启动上位机

```bash
python3 /home/kkozia/alfa_robot_ws/motor_debug/rmd_tuner.py
```

## 三、基本操作流程

### 3.1 连接电机

1. 从 **CAN** 下拉框选择接口 (can0 / can1 / vcan0)，也可手动输入
2. 设置 **电机ID** (1~32)
3. 点击 **[连接]**
4. 状态指示灯变为绿色 **●已连接** 表示成功

连接成功后：
- 自动开始 20ms 间隔的状态轮询 (~50Hz)
- 实时波形开始绘制
- 左下角显示温度、电压、电流、转速等实时数据

### 3.2 读取 PID 参数

| 操作 | 说明 |
|------|------|
| 单环读取 | 点击对应环路框内的 **[读取]** 按钮 |
| 全部读取 | 点击 **[全部读取]**，依次读取角度环、速度环、电流环 |

读取成功后，Kp / Ki / Kd 数值框会自动填入当前电机参数值。

### 3.3 写入 PID 参数

1. 修改目标环路的 Kp / Ki / Kd 数值框
2. 点击该环路的 **[写入RAM]**
3. 状态栏提示写入成功，并自动回读验证
4. 底部调试记录表自动添加一行，记录本次修改

> **注意**: 写入 RAM 掉电后丢失。调试阶段建议始终写 RAM，确认最终参数后再通过其他方式固化到 ROM。

### 3.4 备份与恢复出厂参数

| 操作 | 说明 |
|------|------|
| **[备份出厂]** | 将当前 SpinBox 中的三环参数保存到内存。**建议连接后第一件事就是先读取再备份。** |
| **[恢复出厂]** | 将备份的参数写回电机 RAM，三环全部恢复 |

典型流程：

```
连接 → 全部读取 → 备份出厂 → 开始调参 → (调乱了) → 恢复出厂
```

### 3.5 电机控制

| 按钮 | 命令 | 说明 |
|------|------|------|
| **[运行]** (绿) | 0x88 | 电机使能，恢复运行 |
| **[停止]** (橙) | 0x81 | 电机停止 (保持使能) |
| **[关闭]** (红) | 0x80 | 电机关闭 (释放力矩) |

### 3.6 紧急停止

有两种触发方式：

1. 按键盘 **ESC** 键 (全局快捷键)
2. 点击右上角红色 **[紧急停止 ESC]** 按钮

紧急停止会：
- 通过专用 socket 在 GUI 线程直接发送 0x80 关闭命令 (不受工作线程阻塞)
- 同时通过工作线程再发送一次关闭命令 (双保险)

## 四、实时波形

### 4.1 波形显示

连接后自动开始绘制三个子图：

| 子图 | 数据来源 | 说明 |
|------|---------|------|
| 转速 (dps) | 0x9C 状态2 | 电机转速，单位 dps |
| 位置 (deg) | 0x92 多圈角度 | 输出侧角度 (已除减速比) |
| 转矩电流 | 0x9C 状态2 iq | 转矩电流原始值 |

### 4.2 波形控制

| 操作 | 说明 |
|------|------|
| **[暂停]** / **[恢复]** | 暂停/恢复波形更新，数据采集不停 |
| **[自适应]** | 恢复自动滚动和 Y 轴自适应缩放 |
| **[导出CSV]** | 将缓冲区全部数据导出为 CSV 文件 |
| **鼠标滚轮** | 在波形区域滚动可缩放时间轴和幅值轴 |
| **勾选框** ☑速度 ☑位置 ☑电流 | 选择显示哪些信号 |

### 4.3 缩放与平移

- **滚轮向上**: 放大 (缩小时间/幅值窗口)
- **滚轮向下**: 缩小 (扩大时间/幅值窗口)
- 缩放以鼠标位置为中心
- 手动缩放后自动滚动会关闭，点击 **[自适应]** 可恢复

## 五、阶跃测试

阶跃测试用于观察电机的动态响应，是 PID 整定的核心工具。

### 5.1 位置阶跃

1. 选择 **○位置阶跃**
2. 设置 **幅度** (输出侧角度，单位°，如 30 表示转动 30°)
3. 设置 **最大速度** (dps)
4. 点击 **[执行]**

程序会：
- 读取当前多圈角度
- 计算目标角度 = 当前角度 + 幅度 × 减速比
- 发送 0xA4 多圈位置命令
- 波形面板实时显示响应曲线

**观察重点**: 位置曲线的上升时间、过冲量、振荡次数、稳态误差。

### 5.2 速度阶跃

1. 选择 **○速度阶跃**
2. 设置 **幅度** (目标速度，单位 dps)
3. 点击 **[执行]**

程序会：
- 发送 0xA2 速度闭环命令
- 3 秒后自动发送速度=0 停止

**观察重点**: 速度曲线的响应速度、过冲量、稳态精度。

### 5.3 阶跃测试与 PID 调参配合

推荐工作流：

```
1. 全部读取 PID → 备份出厂
2. 执行阶跃测试 → 观察波形 → 记录现象
3. 修改某个参数 → 写入 RAM (自动记录到日志)
4. 再次执行阶跃测试 → 对比波形
5. 重复 3~4 直到满意
6. 如果调乱了 → 恢复出厂 → 从头来
```

## 六、调试记录

### 6.1 自动记录

每次成功写入 PID 参数后，底部表格自动添加一行：

| 列 | 内容 |
|----|------|
| # | 序号 |
| 时间 | 写入时刻 (HH:MM:SS) |
| 环路 | 角度环 / 速度环 / 电流环 |
| Kp | 写入的 Kp 值 |
| Ki | 写入的 Ki 值 |
| Kd | 写入的 Kd 值 |

Kp、Ki、Kd 列**可编辑**，方便添加备注或修正记录。

### 6.2 导出日志

点击 **[导出日志CSV]**，选择保存路径，生成 CSV 文件记录全部调试历史。

## 七、状态监控与安全

### 7.1 实时状态显示

左下角实时显示：

| 状态 | 说明 |
|------|------|
| 温度 | 电机温度 (°C) |
| 电压 | 母线电压 (V) |
| 电流 | 母线电流 (A) |
| 转速 | 当前转速 (dps) |
| 状态 | 运行 / 关闭 |
| 错误 | 错误标志解析 |

### 7.2 安全保护

| 保护 | 触发条件 | 行为 |
|------|---------|------|
| 过温警告 | 温度 > 70°C | 温度标签变红 + 弹窗警告 (30秒冷却间隔) |
| 错误提示 | 错误标志非零 | 错误标签变红，显示具体错误类型 |
| 紧急停止 | ESC 键 或 按钮 | 立即发送 0x80 关闭命令 |

错误类型包括：低电压保护、高电压保护、驱动过温、电机过温、电机过流、电机短路、电机堵转、输入信号丢失超时。

## 九、技术细节

### 9.1 线程架构

```
主线程 (GUI)                    CAN 工作线程
┌──────────────────┐           ┌──────────────────┐
│ Qt 事件循环       │  信号/槽  │ CanWorker        │
│ 所有 widget 更新  │ ←──────→ │ CAN socket 操作  │
│ matplotlib 绑图   │           │ PID 读写         │
│                   │           │ 状态轮询         │
│ status_timer  20ms│──触发──→ │ poll_status()    │
│ wave_timer   50ms │           │                  │
└──────────────────┘           └──────────────────┘
        │
        │ 紧急停止专用 socket (GUI 线程)
        └──→ 直接发送 0x80, 不经过工作队列
```

### 9.2 CAN ID 约定

| 用途 | TX ID | RX ID | 说明 |
|------|-------|-------|------|
| PID 读写等命令 (send_and_recv) | 0x140 + motor_id | 0x140 + motor_id | 通用命令收发 |
| 状态2 读取 (read_status2_direct) | 0x140 + motor_id | 0x140 + motor_id | 独立实现 |
| 多圈角度 (read_multi_turn_angle) | 0x140 + motor_id | 0x140 + motor_id | 独立实现 |

### 9.3 数据缓冲区

- 环形缓冲区，最大 20000 点
- QMutex 保护，工作线程写入、GUI 线程读取快照
- 存储: 时间戳、转速、位置(输出侧)、转矩电流

### 9.4 减速比

默认减速比为 36 (CanWorker._gear_ratio)。多圈角度读取值为电机侧角度，位置显示值 = 电机侧角度 / 减速比。

如需修改减速比，在源码中搜索 `_gear_ratio = 36` 进行修改。

## 十、故障排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 连接失败 "无法打开 CAN 接口" | CAN 接口未启动 | `sudo ip link set can0 up type can bitrate 1000000` |
| 连接成功但状态全是 "--" | 电机 ID 不对 / 电机未上电 | 确认电机 ID，检查电源和 CAN 接线 |
| PID 读取失败 | 通讯超时 | 检查 CAN 接线，确认波特率匹配 |
| 波形不动 | 勾选框未勾选 / 波形已暂停 | 检查勾选状态，点击恢复 |
| 阶跃测试无响应 | 电机未运行 | 先点击 [运行] 使能电机 |
| 中文显示为方框 | 缺少中文字体 | 安装 SimHei 或 Droid Sans Fallback 字体 |
| 段错误 (segfault) | matplotlib 版本冲突 | `pip install --upgrade matplotlib PyQt5` |

## 十一、配合 PID 整定指南使用

本工具配合 `PID_TUNING_GUIDE.md` 中的整定方法使用效果最佳：

1. 打开上位机，连接电机
2. **全部读取** → **备份出厂**
3. 按照整定指南的步骤，从内环到外环逐环调整：
   - 电流环 (通常不动)
   - 速度环: 先调 Kp → 加 Ki → 可选 Kd
   - 角度环: 先调 Kp → 加 Kd (关键) → 可选 Ki
4. 每次修改后执行**阶跃测试**，观察波形
5. 调试记录自动保存，结束后**导出日志CSV**存档
