# V3 单次舒适高度抓取 Demo（仿真实验版）

在 `feature/wall-box-comfort-height` 上基于仓库/home版本 `cc3aa86` 增量实现，复用原解析 IK、RRT、碰撞场景和服务。不接实机，不自动提交或创建 PR。

> **实验结论：**训练候选 `[1.10,1.15]`、首选 `1.15` 没有通过独立距离的优势验证。保留为实验入口，原默认策略不变；详细成功率及退化见第4节。

## 1. 选高规则

- 中心是**当前选中单臂的肩部三轴公共中心**，不是双肩中点；目标是吸取时的 `contactPose` TCP，不是箱中心。
- `S0` 是初态肩心世界坐标，`P` 是接触 TCP 世界坐标，`q0` 是初始升降值。
- `xy = hypot(Px-S0x, Py-S0y)`；本次操作内水平几何固定。
- `L = 上臂长度 + 前臂长度`，由当前型号的解析几何读取。本模型约 `0.979m`，**不含腕心到 TCP**；所以 `rho > 1` 不等于超出 TCP 可达域。
- `rho(q) = hypot(xy, S0z + q - q0 - Pz) / L`。

对于首选比例 `rho*`，若 `rho*L >= xy`：

```text
equal = q0 + Pz - S0z
q_above/below = equal ± sqrt((rho*L)^2 - xy^2)
```

先从初态固定双臂姿态，在机械限位 `updown∈[-1,0]m` 内以不超过 `5mm` 步长向两端检查整机碰撞；每个方向遇到首个碰撞即停止，以前一个通过检查的位置作为可达边界，不跨越途中障碍。将理想根投影到这个与初态相连的升降区间。运行时还比较等高点及上下限，依次最小化：距比例区间的距离、距首选比例的距离、肩心低于目标的惩罚、升降行程；最后作确定性平局处理。几何分数相同优先肩在目标上方。

**每个臂仅有一个选定高度：先检查升降区间，再做几何选择；不调用 IK 来选高，不按抓取规划成败换高重试。** `auto` 仍是左臂先完整规划，失败后右臂独立选高并完整规划；不是双臂成功结果的 oracle 并集。原规划器在同一高度内已有的 IK/RRT 候选搜索保持不变。

`xy` 太大或可达升降范围导致不能进入区间时，仍使用范围内几何最接近的高度，报告 `xy_exceeds_band` / `reachable_lift_limits`。边界是按上述步长保守采样所得，不是连续碰撞证明；选定后仍复核实际升降轨迹。选定高度合法不代表路径安全：初态、整个升降、预接触、吸附、抽离、携箱回 home 和携箱升回零都必须通过原碰撞检查。失败后不把无效轨迹伪装成成功回放。

## 2. 使用

原 `v3_box_wall_grasp_demo.launch.py` 默认仍为固定肩高差 `0.25m`，**原初始化/重新启动命令不变**。要用这个新实验版，只换 launch 文件名；同 domain 不能同时运行两个版本。

```bash
cd /home/astesia/Sevenova/alfa_robot
source tools/ros_humble_env.sh
source ros2_ws/install/setup.bash
export ROS_LOCALHOST_ONLY=1 ROS_DOMAIN_ID=188  # 先确认空闲

ros2 launch alfa_robot_moveit_config v3_box_wall_comfort_grasp_demo.launch.py \
  x:=0.90 box_id:=5 arm:=auto
```

`x` 仍必填，`arm` 仍为 `left/right/auto`，默认 RViz+Rerun 并运行一次。关闭后重新启动仍执行上述完整命令，不只重发服务请求。`auto_run_once:=false` 只启动场景。`start_rviz:=false start_rerun:=false` 无窗口规划。

服务名与请求格式**完全不变**，第二个终端 source 同样环境并设置相同 ROS domain：

```bash
ros2 service call /v3_box_wall_grasp_demo/plan_wall_box \
  alfa_robot_moveit_config/srv/PlanWallBoxDemo \
  '{x: 0.90, box_id: 5, arm: auto}'
```

可显式覆盖 `comfort_ratio_min / comfort_ratio_preferred / comfort_ratio_max`，必须有限且 `0 < min <= preferred <= max`。`comfort_branch:=above/below` 仅用于离线分支诊断，正常使用 `auto`。`planning_seed:=0` 保留正常随机行为，正整数在 OMPL 初始化前设种子；有时间预算的规划不保证不同负载下逐字节复现。

诊断 JSON 中 `reachable_lift` 给出检查状态、可达上下界与首个阻挡采样点/碰撞对；初始预览 `checked=false` 只是未检查的几何提案，最终结果与每臂 `attempts` 记录实际选高。其余字段提供世界坐标、`xy`、`L`、初始/选定高度比例、区间、分支、理想/投影高度和区间外原因。`actual_ratio` 指**选定高度的几何比例**，不是失败后机械臂实际到达了该高度。每个正常规划尝试的 `height_selections=1` 表示不更换选定高度，不能解读为 IK/RRT 只求解一次。RViz 状态文字和 Rerun 摘要显示同样几何信息；新升降阶段名是 `move_to_grasp_height`，携箱归零仍为 `restore_default_height`。

## 3. 实验合同与复现

> 以下大规模实验及随附 JSON 是**仅按机械限位选高的修正前历史结果**，不代表新增升降碰撞区间约束后的成功率；冻结参数和原始结果未改写。新策略的定点回归记录见文末。

先测 `0.50–1.10`（步长 `0.05`），包含直觉候选 `0.8`；分别运行 `auto/above/below`。初轮发现大量目标比例低于 `xy/L`，多个名义比例产生同一投影高度，不能据此宣布一个物理舒适区间。因此**在使用任何独立验证样本前**记录并扩展训练到 `1.15–1.40`，仍保持 `0.05` 步长和同一预算。

粗扫种子 `104729`；距最高完整成功率不超过2个百分点的运行时候选及固定高度基线，以 `104729/130363/155921` 三个预设种子复测。优先完整成功率，其次共同成功样本上的关节限位裕度中位数、归一化总关节行程、升降行程，最后与 `0.8` 的距离。区间只取包含首选比例的连续近优测试点，不跨越失败谷；单点不称已证实区间。冻结后才测试保留距离，不据其结果回调参数。

## 4. 实验结果与结论

**没有得到跨距离独立验证成立的“优势舒适区间”。** 新逻辑和可复现实验已完成，但不能据此宣布动作更自然，或用它替换原默认策略。

训练集冻结的**候选参数区间**为 `[1.10, 1.15]`，首选 `1.15`；这是本模型、场景和预算下的训练近优点段，不是普适物理舒适区间，也不代表段内每个连续实数都经过验证。新实验 launch 使用这组冻结值；原 launch 仍默认固定 `0.25m`。

| 明确左右臂分别请求，每次全25箱 | 固定0.25m | 新策略 | 说明 |
|---|---:|---:|---|
| 训练：3距离 × 2臂 × 25箱 × 3种子 | 84/450（18.67%） | 102/450（22.67%） | 每种子均28→34 |
| 独立验证：2距离 × 2臂 × 25箱 × 3种子 | 48/300（16%） | 42/300（14%） | 每种子均16→14，发生稳定退化 |

真实 `arm:=auto` 服务的结果如下；每个数是**每种子成功箱数/25**，三个种子结果相同。不是离线左右臂成功并集。

| x（m） | 用途 | 旧策略 | 新策略 |
|---|---|---:|---:|
| 0.80 | 训练距离 | 0/25 | 0/25 |
| 0.85 | 保留距离 | 0/25 | 0/25 |
| 0.90 | 训练距离 | 17/25 | 19/25 |
| 0.95 | 保留距离 | 16/25 | 14/25 |
| 1.00 | 训练距离 | 10/25 | 12/25 |

跨这5个离散距离的 `auto` 总数为 `129/375 → 135/375`，但**包含训练距离，不能拿这个总数覆盖独立验证失败的事实**。具体变化三个种子一致：

- 新增成功：`x=.90` 的12、17号；`x=1.00` 的10、14、15、19号。
- 退化：`x=.95` 的5、9号；`x=1.00` 的6、8号。显式单臂验证中的 `.95` 退化为左5、右9。
- `.80/.85` 在当前流程下两版均无完整成功，主要受携箱 home 与邻箱的碰撞及低位升降约束影响；这不是“绝对不可抓取”的证明。

共同成功样本上的指标也不支持“姿态全面改善”（数值是各自样本分布的中位数，并非逐对差值中位数）：

| 指标，旧→新 | 训练共同成功78请求 | 独立验证共同成功42请求 |
|---|---:|---:|
| 最小归一化关节限位裕度（越大越好） | 0.07414→0.06304 | 0.07661→0.05803 |
| 归一化总关节行程（越小越好） | 2.84063→3.27417 | 2.75267→3.18771 |
| 升降行程中位数（m） | 0.12927→0.62927 | 0.12927→0.62927 |

在原始训练粗扫中，`auto` 的首选比例 `.50–1.05` 大部分成功30/150（`.55` 为29/150）；`1.10` 为32/150，`1.15` 为34/150，`1.20` 为30/150，`1.25–1.40` 为0/150。对 `1.10/1.15` 的三种子复测均分别为32/150、34/150。强制上下分支均完整测过；`1.15` 的 above 为34/150、below 为26/150，**没有采用按箱号事后挑选成功分支**。

扫描到 `.50–1.05` 的平台大部分来自目标半径不可达后的相同投影，不是证实 `0.8L` 舒适。完整扫表、失败阶段、共同样本指标与逐种子退化清单见同目录 `V3单次舒适高度实验.json`；所有原始响应保存在证据根目录。

结论：只用肩心到 TCP 的距离比例，不能同时表达关节姿态、地面间隙、邻箱遮挡及携箱 home 的可行性。本次验证后**不回调参数、不增加换高重试、不缩碰撞几何、不扩大 IK/RRT 预算**。若继续追求“自然”而非仅几何选高，需要另立实验修改目标函数；不能把本轮未证实的优势写成验收通过。
