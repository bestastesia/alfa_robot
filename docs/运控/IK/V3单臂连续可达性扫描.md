# V3 单臂连续可达性扫描

该工具用于判断单臂末端能否在固定姿态下，沿机器人正前方连续运动 `40cm`。

同一工具支持三种测试：

- `test_pattern:=linear_x travel:=0.0`：单点可达性。
- `test_pattern:=linear_x travel>0`：沿 `base_link +X` 连续平移。
- `test_pattern:=planar_disk`：固定末端朝向，在每个中心点周围的 `base_link YZ` 平面测试局部圆盘平移连续性。

## 判定口径

- `base_link +X` 是机器人正前方，扫描运动沿 `+X`。
- 在 `X/Y/Z` 三维空间中均匀选取独立起点。默认起点范围为 `X=0.35～0.75m`、`Y=-0.55～0.85m`、`Z=0.05～1.20m`。
- 每个起点都独立沿 `+X` 平移 `40cm`，每 `1cm` 求一次 V3 冗余解析 IK。例如 `X=0.35m` 和 `X=0.36m` 是两次互不继承的完整测试。
- 下一点以上一点关节解和冗余角 `ψ` 为参考，优先选择最近的连续分支。
- `10°` 是高关节增益质量门槛，不再作为连续性硬失败条件。超过该值但路径合法的边标记为“连续但高关节增益”，后续执行必须降低末端速度或重新优化冗余角。
- 相邻解之间按最大 `2.5°` 关节步进插值，并使用 MoveIt PlanningScene/FCL 检查碰撞。同一批插值状态同时检查末端 FK 是否跟随目标笛卡尔线段，默认最大位置/姿态偏差为 `1mm/1°`。
- 高关节增益边只额外检查当前冗余角附近 `±2` 档候选。直接边失败时最多进行三层笛卡尔二分，最小步长 `1.25mm`，额外搜索预算默认 `2ms`。
- 只有目标无解析解、所有候选碰撞，或受限细分后仍无法形成满足任务路径误差的连续边时，才判定为不连续。
- 单臂测试忽略另一只机械臂，但保留测试臂自碰撞以及测试臂与立方体本体的碰撞。

只有从该起点出发的整条 `40cm` 轨迹全部通过时，该起点才判定连续；舒适连续点显示为绿色，高关节增益连续点显示为青色，未能完整通过的测试起点显示为红色。Rerun 不记录中间轨迹采样点。

圆盘模式默认测试半径 `15cm`，以 `3cm` 径向间距布置同心环，沿每个圆环按约 `1cm` 的弧长连续采样。测试从圆心开始，依次径向进入并完整走过每个圆环；全部采样点的解析IK、任务路径和插值碰撞检查均通过，中心点才判定连续。末端朝向全程固定。

## 运行

```bash
cd /mnt/mydisk/ALFA/alfa_robot_v3/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash

ros2 launch alfa_robot_moveit_config v3_continuous_reachability.launch.py \
  side:=left \
  x_start_min:=0.35 \
  x_start_max:=0.75 \
  x_start_step:=0.01 \
  output_json:=/tmp/v3_left_continuity.json
```

生成 Rerun：

```bash
ros2 run alfa_robot_moveit_config visualize_v3_continuous_reachability.py \
  /tmp/v3_left_continuity.json \
  --save /tmp/v3_left_continuity.rrd

rerun /tmp/v3_left_continuity.rrd
```

半径 `15cm` 圆盘平移连续性：

```bash
ros2 launch alfa_robot_moveit_config v3_continuous_reachability.launch.py \
  side:=left \
  test_pattern:=planar_disk \
  x_start_min:=0.15 x_start_max:=0.75 x_start_step:=0.01 \
  lateral_min:=-0.20 lateral_max:=1.40 lateral_step:=0.05 \
  height_min:=-0.75 height_max:=1.25 height_step:=0.05 \
  disk_radius:=0.15 disk_ring_step:=0.03 path_step:=0.01 \
  maximum_joint_delta_deg:=10.0 \
  output_json:=/tmp/v3_left_disk_continuity.json

ros2 run alfa_robot_moveit_config visualize_v3_continuous_reachability.py \
  /tmp/v3_left_disk_continuity.json \
  --save /tmp/v3_left_disk_continuity.rrd
```

- 绿色：该中心周围半径 `15cm` 的圆盘路径全程连续、无碰撞，且没有超过 `10°` 的高关节增益边。
- 青色：全程连续、无碰撞，但至少存在一条超过 `10°` 的高关节增益边。
- 红色：圆盘路径中至少一个点无解析解、碰撞，或关节插值无法保持目标笛卡尔路径。

针对局部红区生成失败原因诊断 Rerun：

```bash
ros2 run alfa_robot_moveit_config visualize_v3_continuous_reachability.py \
  /tmp/v3_left_disk_continuity.json \
  --failure-details --y-min 0.8 --z-min 0.4 \
  --save /tmp/v3_left_disk_upper_left_diagnostics.rrd
```

如需串行播放“某一网格轴前后相邻中心均成功、当前中心因碰撞失败”的完整轨迹，扫描时增加
`record_failure_paths:=true record_failure_states:=true`，再运行：

```bash
ros2 run alfa_robot_moveit_config visualize_v3_continuous_reachability.py \
  /tmp/v3_left_disk_continuity.json \
  --sandwiched-collision-playback \
  --playback-fps 20 --collision-hold-s 1.0 \
  --save /tmp/v3_left_sandwiched_collision_playback.rrd
```

每段从该中心的圆盘起点连续播放到失败插值帧。最后一帧停留并使用红色包围盒标出
MoveIt/FCL 报告的碰撞 link；右侧面板显示中心坐标、失败步骤和原始碰撞对。

诊断颜色中，深红表示中心点立即无解析解，橙色表示中心可达但圆盘路径进入不可达区，紫色表示关节插值偏离目标路径，黄色表示碰撞。箭头从测试中心指向实际失败的圆盘采样点。旧数据中的“相邻关节变化超过 `10°`”仍保持紫色，便于和新口径比较。

如需逐帧查看失败时的机械臂姿态，扫描时增加 `record_failure_states:=true`，可视化时增加 `--failure-poses`。关节跳变失败会显示最小跳变候选姿态；碰撞失败会显示真正发生碰撞的插值帧；无解析解时显示最后一个合法姿态。

- 绿色：从该 XYZ 起点出发能够完整、连续、无碰撞地走完 `40cm`。
- 红色：该 XYZ 起点经过测试，但无法完整走完 `40cm`。

范围、空间采样分辨率、高关节增益门槛、任务路径误差、受限细分预算和冗余角采样分辨率均可通过 launch 参数修改。

仅用于安装位置敏感性测试时，可通过 `arm_mount_forward_offset` 将左右臂安装点同时沿
`base_link +X` 前移；默认值为 `0`，不会改变普通模型和 Demo。例如前移 `10cm`：

```bash
ros2 launch alfa_robot_moveit_config v3_continuous_reachability.launch.py \
  arm_mount_forward_offset:=0.10 # 其余扫描参数保持不变
```

## V3.0.6 扩展空间结果

统一扫描空间为 `X=0.15～1.35m`、`Y=-0.30～1.40m`、`Z=-0.75～1.25m`，共 `173,635` 个独立中心：

- 单点可达 `65,845` 个，比例 `37.92%`，耗时 `131.73s`。
- 向前连续 `40cm` 成功 `26,012` 个，比例 `14.98%`，耗时 `912.28s`。
- 周围半径 `15cm` 圆盘连续成功 `35,757` 个，比例 `20.59%`，耗时 `1745.54s`。

结果位于 `data/ik_benchmark/v3_0_6_extended_reachability/`。三项测试均使用 V3.0.6 冗余解析 IK、当前关节限位、MoveIt/URDF FK 路径复核和 PlanningScene/FCL 碰撞检测。

## 新旧判定对比

针对原关节跳变红区 `X=0.15～0.75m、Y=0.20～0.60m、Z=0.50～0.95m` 的 `5490` 个圆盘中心：

- 旧版使用 `5° ψ` 和 `10°` 硬门槛时完整通过 `2396/5490`，通过率 `43.64%`。
- 新版完整通过 `4272/5490`，通过率 `77.81%`；其中绿色舒适中心 `2368` 个，青色高关节增益中心 `1904` 个。
- 受限细分共尝试 `880` 次，恢复 `181` 条局部边，使额外 `15` 个完整中心通过；`699` 次在预算内未找到有效补救。
- 新版总耗时 `73.55s`。关闭有效细分补救时同版核心判定耗时 `68.21s`，有限补救增加约 `7.8%`。
- FK任务路径检查共 `4,023,244` 次，累计 `4.46s`，复用了已有碰撞插值状态，没有重复建立另一套采样。
