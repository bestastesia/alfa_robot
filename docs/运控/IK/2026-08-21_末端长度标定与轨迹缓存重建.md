# 末端长度标定与轨迹缓存重建

## 标定结果

- 左右工具末端固定长度由 `0.259m` 调整为 `0.243m`，缩短 `16mm`。
- `updown=0.4m`、`joint2=90°`、其余关节为零时，工具末端 Z 由约 `0.91059m` 变为 `0.92659m`；实测约 `0.937m`，残差约 `10.4mm`。
- 再令 `joint4=-90°` 时，工具末端 Z 仍约 `1.38609m`；实测约 `1.376m`，残差约 `10.1mm`。
- 两个姿态残差绝对值基本一致、方向相反，符合约 `1cm` 的人工测量/参考面误差；`16mm` 末端长度修正量成立。
