# V3 双臂异构握持同步平移 Demo

## 目标

验证双臂以不同末端朝向刚性握持同一个 `0.30m` 正方体，并沿用户指定方向完成同步笛卡尔直线运动：

- 右臂从箱体侧面水平握持；
- 左臂从箱体底面向上支撑；
- 箱体与两只末端的相对位姿在运动中保持不变；
- 箱体作为附着物参与机器人自碰撞和本体碰撞检查。

## 算法

1. 用户在 RViz 中拖动青色控制球，只修改箱体目标中心位置。
2. 算法按 `1cm` 对箱体中心直线插值。
3. 每个采样点分别生成左右七轴冗余解析 IK 候选。
4. 联合选择两臂均满足关节限位、最大关节步进和完整场景碰撞约束的候选对。
5. 对相邻状态同步插值复检，左右臂使用同一时间比例，不允许一只手先到。

本 Demo 的运动路径不调用 KDL 或 OMPL。默认严格保持左侧末端工具法向朝世界 `+Z`，不会通过倾斜末端伪装“向上支撑”。

## 默认测试位

- 箱体中心：`[0.75, 0.00, 1.44]m`
- 默认目标：沿世界 `-X` 平移 `0.10m`
- 左臂底面接触点：箱体中心左侧 `0.15m`、下方 `0.15m`
- 右臂侧面接触点：箱体中心右侧 `0.15m`

严格向上支撑姿态在当前机械结构和关节限位下位于较高工作区。更低的默认箱位解析 IK 无合法解，因此没有通过放宽碰撞或倾斜末端强行通过。

## 启动

```bash
cd /mnt/mydisk/ALFA/alfa_robot_v3/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch alfa_robot_moveit_config v3_dual_arm_asymmetric_box_demo.launch.py
```

在 RViz 中拖动青色球后，右键选择“确认并计算当前箱位”。RViz 和 Rerun 会同步播放成功轨迹；失败时保留当前位置并显示失败阶段和原因。

可切换镜像握持：

```bash
ros2 launch alfa_robot_moveit_config v3_dual_arm_asymmetric_box_demo.launch.py \
  grasp_pattern:=left_side_right_bottom
```

## 当前验证

默认沿 `-X` 平移 `0.10m`：

- 结果：成功；
- 轨迹：11帧；
- 总计算：约 `17.6ms`；
- 解析 IK：1540次，累计约 `12.5ms`；
- 碰撞检查：21次，累计约 `1.6ms`。

同时回归通过原双臂同步平移和双臂绕箱体中心旋转 Demo。
