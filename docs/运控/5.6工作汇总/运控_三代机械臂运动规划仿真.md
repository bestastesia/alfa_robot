# 运控 - 三代机械臂运动规划仿真

**完成日期：** 2026/05/01

## 核心成果

基于 v3 完整 URDF 模型完成了运动规划仿真环境的搭建，可在 RViz + MoveIt 中进行双臂协调运动规划验证。仿真环境涵盖了完整的规划管线：运动学求解 → 轨迹规划 → 碰撞检测 → 控制器执行。

运动学求解方面，经过对比验证确定了各规划组的求解器方案：

- `dual_arm_with_base`（双臂+升降+转盘，树结构）：BioIK——唯一能处理多末端执行器树结构的求解器
- `left_arm` / `right_arm`（单臂链式结构）：pick_ik——计算效率高，适合单臂快速求解

此前经历过一次关键排错：dual_arm_with_base 的求解器曾被改为 pick_ik，而 pick_ik 无法处理树结构的多末端执行器 IK 求解，换回 BioIK 后恢复正常。KDL 同样无法处理树结构，只有 BioIK 原生支持。

**代码位置：** [kinematics.yaml](../../src/alfa_robot_moveit_config/config/kinematics.yaml)（求解器配置）/ [moveit_controllers.yaml](../../src/alfa_robot_moveit_config/config/moveit_controllers.yaml)（控制器映射）

## 当前效果

RViz 中双臂交互式标记正常显示，拖动标记后 MoveIt 可成功规划出无碰撞路径并执行仿真运动。单臂规划响应快速，双臂协调规划可正常求解，但相比单臂规划耗时明显增加，实时性有待优化。碰撞检测生效，规划时自动避开自碰撞和与环境障碍物的碰撞。

## 测试方法

- RViz 中拖动左臂/右臂交互式标记，确认规划成功且轨迹合理
- 将双臂拖到接近自碰撞的姿态，确认 MoveIt 规划出避碰路径
- 切换 `dual_arm_with_base` 求解器为 pick_ik 或 KDL，验证标记消失，换回 BioIK 后恢复
- 观察双臂协调规划的求解耗时，评估实时性

## 存在问题与后续方向

双臂协调规划耗时较长（2~5s），难以满足产线节拍要求。BioIK 虽然能求解，但搜索分辨率和迭代次数的配置对求解质量和速度影响很大，当前参数仍较保守。仿真环境暂未加入工件和环境障碍物的碰撞模型，与实际产线场景有差距。后续需优化 BioIK 参数提升求解速度，并逐步加入产线环境模型。
