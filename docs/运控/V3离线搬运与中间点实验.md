## 当前实现边界

接触前、接触、附着及笛卡尔抽离沿用主干流程。抽离后分为：

1. `rrt_to_midpoint`：动态规划到固定七轴中间关节状态。
2. `offline_carry`：原样读取已离线生成的中间关节状态→后方放置点。
3. `rear_placement` / `release_box`：原主干放置与释放。

默认 `transfer_mode=disabled`，行为及旧双臂阶段编号不变。

`build` 模式可调用放置 IK、RRT，并用确定性碰撞检测 shortcut 减小后段路径长度，
写入 JSON；同一个配置只生成一次。`use` 模式只读 JSON，不调用后段规划、放置 IK
或后段优化。缺失、不兼容、关节越界、碰撞、接缝不一致和错误放置位姿均拒绝，
不偷偷退回完整在线规划。已有前/顶吸及换臂尝试仍保留。

中间点来自 SRDF `whole_body/home` 或 `transfer_named_pose`；可用
`transfer_joints_json` 覆盖左右臂各七个弧度值。**这里只固定臂关节，升降高度仍保持
每次抓取的高度**，因此是按高度分组的中间点族，不是所有高度共用一个绝对 TCP 位姿。
是否加入统一升降高度以及带负载升降归一化，需要后续实验；不能把当前实现宣传为
已找到唯一全局最优中间位姿。

缓存兼容性包括完整 URDF/SRDF 文本、所有非活动臂关节、七轴中间状态、
前/顶吸变换、箱体尺寸及后方放置几何。当前场景不纳入缓存键，但**每次使用必须
重新检查整机、负载和当前环境的所有后段状态与插值边**。障碍物变化可能使离线轨迹
失效；拒绝是预期行为。保留验证的在线计算成本，实验必须把它算进总耗时。
每个文件仅支持一个离线写入进程；写入使用临时文件+原子替换。

双臂动态段与离线段分别对齐阶段，合成后仍运行原主干独立的整机/双负载碰撞验证。
合成的索引同步是主干已有的运动学采样，不代表离线联合优化或动力学同步。

缓存只有关节位置，不包含经过验证的速度/加速度/jerk时间律。接缝仅保证位置连续；
实机必须另行制定停止接缝或统一时间参数化，不能直接播放该仿真轨迹执行搬运。
shortcut 只是局部路径长度优化，不是全局最优性证明。

## 可重复实验

下面命令保持环境碰撞检查开启，按墙序列前缀保留邻箱，比较主干基线与相对
home 的 0/20/40°固定肩部方位与 90/140°肘部候选；每个候选先离线生成，再用新进程、只读缓存
测量在线规划。每个成功结果通过已有独立 C++ 回放验证器。

```bash
cd /home/astesia/Sevenova/alfa_robot && source tools/ros_humble_env.sh && source ros2_ws/install/setup.bash && cd ros2_ws && colcon build --packages-select alfa_robot_description alfa_robot_analytic_ik alfa_robot_moveit_config --cmake-args -DBUILD_TESTING=ON -DPython3_EXECUTABLE=/usr/bin/python3
cd /home/astesia/Sevenova/alfa_robot && source tools/ros_humble_env.sh && source ros2_ws/install/setup.bash && ROS_DOMAIN_ID=196 /usr/bin/python3 tools/benchmark_v3_transfer_midpoints.py --artifacts /tmp/alfa-transfer-matrix-20260917 --x 0.5 --box-ids 9 14 19 --seeds 42 43 44 --yaw-offset-deg 0 20 40 --elbow-deg 90 140 --arm left
```

产物：逐次 result JSON、URDF/SRDF、独立回放验证日志、后段缓存、`records.json`
及 `summary.json`。如有全覆盖的 Pareto 可行候选，输出 `selected_midpoint.json`
作为实验推荐配置，仍需保留样本验证后再部署。`manifest.json` 固定二进制哈希，禁止在
对比过程中重新构建。在线运行断言缓存文件哈希不变，后段与缓存完全一致，放置 IK
和后段规划调用均为零，动态末帧与后段首帧完全相同。

比较顺序：成功覆盖率优先，再看总在线耗时、动态段耗时、后段碰撞复验耗时、
碰撞检查/IK次数、加权关节路径长度与关节方向反转次数。输出延迟/路径长度的
Pareto 标记；不以“距离最近”作为选择规则。TCP距离和关节距离都记录下来，
用来检验“越近越好”，而不是作为未经验证的结论。
方向反转和路径长度只是位置轨迹自然性的代理，不是 jerk 或实机能耗。

当前候选网格、训练/测试任务与种子只是有限样本。默认参数不能根据一次两箱烟测
自动修改；还需要左右臂、前/顶吸、整墙25箱、不同墙距及变化障碍物的保留样本测试。

## 2026-09-17 验收记录

以下结果均来自同一份构建产物，启用环境碰撞检查，并由独立的
`validate_v3_wall_replay` 再次回放验证。它们用于验证机制和选择方法，不构成全局最优或
实机安全证明。

### 后段持久化与新进程只读复用

左臂、顶吸、箱 9、seed 42、肩部方位相对 home +20°、肘部 140°：

| 模式 | 总耗时 | 动态段耗时 | 后段复验 | 后段点数 | 放置 IK | 后段规划 | 结果 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 主干基线 | 27453.98 ms | — | — | — | — | — | 成功，独立回放通过 |
| build | 43337.71 ms | — | — | 8 | 1 | 1 | 成功，25 次 shortcut 检查 |
| fresh `use` | 20488.58 ms | 8695.58 ms | 2759.99 ms | 8 | 0 | 0 | cache hit，独立回放通过 |

`use` 在新进程中运行；缓存文件哈希在调用前后不变，动态末帧与缓存首帧完全一致，
回放中的后段也与持久化条目逐点一致。该样本证明后段可以一次生成并只读复用，且在线
阶段没有调用后方放置 IK 或后段规划。build 的离线耗时不计入在线排名。

该样本的主干加权关节路径长度为 11.614、方向反转 9 次；缓存方案分别为 25.523 和
23 次。虽然在线总耗时下降约 7 秒，位置轨迹代理指标反而更差，因此只能视为一个
延迟/轨迹自然性的 Pareto 权衡，不能称为“更优轨迹”或全局最优。

### 同一高度的后段复用

左臂顶吸、箱 8 与箱 9 使用同一高度组。箱 8 build 一次生成 8 点后段；随后 box 9 的
build 已直接 cache hit，放置 IK 与后段规划调用均为零。两个 fresh `use` 都 cache hit、
后段规划和放置 IK为零，并通过独立回放：

- box 8：23539.82 ms；
- box 9：23848.30 ms；
- 同组主干基线中位数：21004.02 ms；
- 缓存 `use` 中位数：23694.06 ms。

这证明当前按升降高度分组的 key 可以跨同高度接触点复用后段，也说明缓存不必然更快：
当前场景下每次在线碰撞与插值边复验的成本不可忽略。

### “离接触点越近越好”并非单调规则

同为左臂顶吸、箱 9、seed 42、肘部 140°：

| 肩部偏移 | 抽离点→中间点 TCP 距离 | 动态规划耗时 | 在线总耗时 |
| --- | ---: | ---: | ---: |
| +10° | 0.431112 m | 12885.52 ms | 27270.47 ms |
| +30° | 0.471625 m | 12019.52 ms | 26324.95 ms |

两者均 cache hit，放置 IK 与后段规划调用为零，并通过独立回放。+30° 中间点更远，
动态规划和总耗时却更低。该有限单样本足以否定“距离越近，规划成本必然越低”的单调
假设；距离应作为观测特征，而不是单独的优化目标。候选选择仍应先最大化任务覆盖率，
再联合比较在线延迟、复验成本、加权路径长度和方向反转次数。

### 已观察到的不可行候选

- 肘部 90°：固定带载中间状态与 `caster04/chassis_base/model_base` 碰撞，约
  2.66 秒即在昂贵规划前拒绝，IK 调用为零。
- 肩部 0°、肘部 140°：后段与 `neighbor_box_4` 碰撞，离线生成失败。
- 肩部 +40°、肘部 140°：离线 RRT 失败，诊断显示带载箱体或臂车沿途碰撞。

因此主干已有的基础中间点也必须接受与其他候选相同的可行性验证，不能因“已有”或
“更近”而默认采用。

### 当前结论与剩余验证

已验证的是：后段真正持久化、新进程只读复用、在线零后段规划/零放置 IK、缓存失败时
fail closed、同高度接触点复用，以及距离并非单调目标。尚未验证的是：全局最优中间点、
所有升降高度共用的绝对 TCP 中间位姿、速度/加速度/jerk 连续性、实机安全与节拍，以及
左右臂、前/顶吸、整墙 25 箱、多墙距和变化障碍物的完整保留样本覆盖。任何默认中间点
调整都应在这些 heldout 任务完成后再决定。
