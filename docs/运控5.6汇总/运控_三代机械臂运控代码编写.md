# 运控 - 三代机械臂运控代码编写

**完成日期：** 2026/05/01

## 核心成果

完成了三代机械臂（v3）的运控代码编写，核心是构建了基于 MoveIt2 的完整运动控制框架。URDF 模型从二代的双 4DOF 升级为双 6DOF，右臂通过 Y 轴镜像与左臂对称，新增 rightjoint5（continuous 旋转）和 rightjoint6（prismatic 平移），所有 STL 网格也完成了镜像处理。

配套的配置文件全部同步更新：

- SRDF 中添加了 rightjoint5/6 到右臂组和双臂组，以及对应的命名姿态
- ros2_controllers 和 moveit_controllers 统一为单个 `dual_arms_controller`（15 关节），避免命令接口资源冲突
- joint_limits.yaml、initial_positions.yaml 等均补充了新关节参数
- 双臂规划节点 `dual_arm_planner_node` 的右臂末端执行器更新为 `rightjoint6_link`

**代码位置：** [alfa_robot_macro.xacro](../../src/alfa_robot_description/urdf/alfa_robot/alfa_robot_macro.xacro)（URDF）/ [alfa_robot.srdf](../../src/alfa_robot_moveit_config/config/alfa_robot.srdf)（SRDF）/ [ros2_controllers.yaml](../../src/alfa_robot_moveit_config/config/ros2_controllers.yaml)（控制器）

## 当前效果

v3 完整模型可在 RViz 中正常加载，15 个关节的 position command/state 接口均可被 MoveIt 控制。左臂 6DOF + 右臂 6DOF + 升降 + 转盘的完整构型已可运行。单个 `dual_arms_controller` 避免了之前多控制器争用命令接口的问题。

## 测试方法

- RViz 中加载 MoveIt 配置，确认双臂交互式标记正常显示且可拖动
- 通过 MoveIt GUI 分别规划左臂和右臂运动，验证路径执行正确
- `ros2 control list_controllers` 确认 `dual_arms_controller` 为 active 且无资源冲突
- 拖动右臂 newjoint5/6 的交互式标记，验证连续旋转和平移运动正常

## 存在问题与后续方向

右臂 joint5/6 目前在硬件接口层为 PlaceholderJoint 占位，尚无实际驱动对接，需要在确定电机选型后补充驱动层实现。URDF 中右臂的动力学参数（惯性/质量）沿用了左臂的数值，尚未根据实际测量修正。后续还需配合实机调试校准各关节零点和方向参数。
