# 电控 - 位置环调试与平滑运动控制

**完成日期：** 2026/05/01

## 核心成果

在底层驱动基础上完成了零差云控电机的位置环闭环调试。`ZeroerrJoint` 关节层实现了从上层弧度指令到电机脉冲的完整换算链路——经软限位截断后换算为脉冲值，通过即发即弃策略下发到 CAN 总线，下一周期从总线读取实际位置并转回弧度反馈给上层。

平滑运动的实现依赖电机控制器内置的梯形速度规划：电机收到目标位置后自动执行加速→匀速→减速的梯形曲线，软件层无需额外插值，只需每个周期下发最新目标位置即可。同时通过以下参数处理了关节个体差异：

- `sign` 参数：反转关节方向
- `initial_counts`：对齐 URDF 零点与机械零点
- 速度/加速度通过数值微分导出，供上层监测

**代码位置：** [zeroerr_joint.hpp](../../src/alfa_robot_hardware/include/alfa_robot_hardware/joint/zeroerr_joint.hpp) / [zeroerr_joint.cpp](../../src/alfa_robot_hardware/src/joint/zeroerr_joint.cpp)

## 当前效果

MoveIt 滑块拖动后关节平滑跟随，无阶跃抖动。leftjoint2（continuous）可连续旋转，leftjoint3 在限位范围内平滑运动。即发即弃策略确保同一总线上多关节命令同步发出，互不阻塞。

## 测试方法

- MoveIt GUI 滑块控制，观察电机运动平滑性
- `ros2 topic echo /joint_states`，确认位置和速度值合理
- 发送已知角度（如 π/2），角度尺测量实际角度，评估精度
- 同时移动 leftjoint2 和 leftjoint3，验证多关节不阻塞

## 存在问题与后续方向

速度/加速度通过数值微分计算，控制周期波动会放大高频噪声。所有零差电机共用相同的运动参数，无法针对不同关节独立配置。没有到位判断机制，依赖上层控制器判断。后续计划将运动参数做到关节级可配置，对高频轨迹场景增加软件层插值，并对数值微分输出加低通滤波抑制噪声。
