# 电控 - 基础运动安全功能

**完成日期：** 2026/05/01

## 核心成果

实现了驱动层、关节层、硬件接口层三层运动安全机制：

- 驱动层：电机失能、紧急制动（RMD 抱闸、CANopen QuickStop）
- 关节层：软限位截断超限命令；位置误差监控（动态阈值 0.1rad / 静态阈值 0.02rad / 容忍 1s）
- 硬件接口层：急停双通道响应 + deactivate 时可选安全归位（30s 超时保护）

急停触发后阻断所有写操作并驱动各关节执行制动，解除后可恢复控制。`continuous` 类型关节不受软限位限制。

**代码位置：** [i_joint.hpp](../../src/alfa_robot_hardware/include/alfa_robot_hardware/joint/i_joint.hpp)（软限位/误差监控）/ [alfa_robot_hardware.cpp](../../src/alfa_robot_hardware/src/alfa_robot_hardware.cpp)（急停/安全归位）

## 当前效果

软限位有效截断超限命令，急停响应 < 50ms 且可恢复，位置异常产生 WARNING/ERROR 日志，安全归位可靠且超时不卡死。

## 测试方法

- 发送超出限位范围的命令，验证截断效果
- `cansend can0 7FF#01` 触发急停，验证电机立即停止
- 运动中手动阻挡关节，验证误差日志报警
- deactivate 时确认关节归位且不卡死

## 存在问题与后续方向

当前最大问题是位置误差仅产生日志报警，不主动触发急停或减速，需要人工干预。缺少电流/力矩监测，碰撞只能通过位置误差间接推断，响应不够及时。急停解除后不检查电机错误码，可能带病恢复。安全位置固定为零点，未考虑当前构型。后续计划将误差超限与急停/降速联动，增加错误码定期巡检和电流监测实现碰撞检测，并发布诊断话题供外部监控。
