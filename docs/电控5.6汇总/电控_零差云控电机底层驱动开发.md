# 电控 - 零差云控电机底层驱动开发

**完成日期：** 2026/05/01

## 核心成果

基于零差云控电机的 CAN 通信协议，开发了 `ZeroerrDriver` 驱动类，通过 Linux SocketCAN 原生接口实现与电机控制器的直接通信。驱动覆盖了以下完整功能：

- 电机使能/失能、运动模式切换（位置/速度/连续/绝对/相对）
- 位置读写、速度与加速度参数设置
- 错误码与运行状态查询
- 即发即弃写策略——发送命令帧后不等待响应，下一周期读取时统一清空残留帧，避免阻塞控制循环

**代码位置：** [zeroerr_driver.hpp](../../src/alfa_robot_hardware/include/alfa_robot_hardware/driver/zeroerr_driver.hpp) / [zeroerr_driver.cpp](../../src/alfa_robot_hardware/src/driver/zeroerr_driver.cpp)

## 当前效果

CAN 通信稳定运行，帧间隔约 200μs，单次超时保护 100ms。电机初始化流程完整：使能 → 位置模式 → 绝对运动模式 → 运动参数设置，一气呵成。同一总线上 Node 1/2 通过帧 ID 正确区分，互不干扰。即发即弃模式实现了通信与控制的解耦。

## 测试方法

- `candump can0` 监听总线，确认帧格式正确
- MoveIt 滑块控制，验证电机平滑跟随
- 断开 CAN 总线后发送命令，验证超时日志正常且不崩溃
- 人为触发电机过流错误，验证错误码读取接口正确捕获

## 存在问题与后续方向

当前运动参数硬编码在默认值中，运行时无法动态调整，不同场景（高速搬运 vs 精密装配）无法适配。缺少心跳检测，电机掉线只能等命令超时才感知。命令失败无自动重试。后续计划将运动参数可配置化、添加心跳监控与自动重连、扩展电流/力矩读取为力控做储备。
