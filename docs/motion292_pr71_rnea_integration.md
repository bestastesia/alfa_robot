# MOTION-292：接入 MOTION-288 / PR #71 固定路径动力学基线

当前 stacked base：`feature/motion-288-dynamic-trajopt@73f40c5`。新分支只扩展滚动重规划，不改写 PR #71 的固定路径时间化和 RNEA 合同。

## 运行合同

1. 上游完整规划先生成固定 q 路径，再执行时间参数化、逐帧 RNEA、局部 C2 时间缩放（失败时统一缩放）和控制器导出。
2. 滚动接续点只能选上游已认证的控制器采样时刻；派生后缀保留父轨迹 SHA-256 和源采样索引。
3. 最新场景下旧后缀仍安全时，直接复用其上游动力学证书，不调用在线 TrajOpt，也不重复 RNEA。
4. 障碍阻断旧后缀时，在线搜索/TrajOpt可以产生新的 q 几何；非零边界候选只做 RNEA audit，禁止通过重定时修改接续速度或加速度。
5. 非零边界候选超出持续力矩门限时，先生成平滑 braking；静止后的 rest-to-rest 尾段才允许使用 PR #71 的固定 q 重定时。最终拼接轨迹再次执行 RNEA audit。
6. 任何计算、通信、准入、碰撞或动力学门禁失败都不安装候选，返回独立安全处置要求。

## 动力学默认值

- 单手载荷：10 kg。
- 箱体尺寸：0.3 × 0.4 × 0.4 m。
- 持续力矩门限：额定合同的 90%。
- CLI与Viser均可在每轮启动前覆盖单箱质量；运行中的质量合同保持冻结，不能中途修改。

## 时间预算

执行期只使用分阶段 `t2_rolling`，`t2_first=t2_rolling+3.5s`仅作为 worker 启动预热门禁，不进入执行期切片：

| 阶段 | t2_rolling | t3 | t4 |
|---|---:|---:|---:|
| 初始姿态→预接触点 | 1.00s | 0.15s | 0.05s |
| 最后3厘米贴近 | 0.10s | 0.15s | 0.05s |
| 抽离35厘米 | 0.35s | 0.15s | 0.05s |
| 携箱运输 | 0.75s | 0.15s | 0.05s |
| 固定底盘放箱 | 0.90s | 0.15s | 0.05s |
| 返回初始姿态 | 1.00s | 0.15s | 0.05s |

每次从当前墙钟位置向后选择首个满足 `lead >= t2+t3+t4` 的已认证采样点，不使用固定切片数。

## 证据与可视化

- 安全关键 worker 回复只带动力学摘要；完整 torque/gravity、RNEA 前后轨迹写入原子 JSON sidecar，并在 verifier 中校验 SHA-256。
- Viser 显示三层路径：灰色上游认证轨迹、橙色 RNEA 前避障候选、红/蓝粗线 RNEA 后实际安装轨迹。
- RNEA 前后双影子使用同一墙钟播放，用于验证 q 路径不变而时间律可不同。
- 本分支仍是仿真与规划合同，不发送实机命令，不替代独立保护停止。

## 验收入口

- `tools/v3_rolling_prepare.py`：生成当前完整周期和阶段动力学证书。
- `tools/v3_rolling_replan.py`：单阶段墙钟滚动模拟。
- `tools/v3_rolling_round.py`：六阶段复用同一预热 worker。
- `tools/v3_verify_rolling.py`：源码、模型、碰撞、动力学和 sidecar 独立审核。
- `tools/v3_rolling_interactive.py`：三层轨迹、双影子和动力学曲线。

GPU 正式证据必须在隔离 runtime 中串行生成；仓库中的旧 PR #65 证据只能作为历史数据，不能冒充本版本验收。
