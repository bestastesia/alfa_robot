## 3. 差异根源总结

所有差异归结为一个原因：**ec_dev 右臂只有 3 个关节，v3_dev 右臂有 5 个关节**。

这个差异引发的连锁反应：
1. **URDF/SRDF**: 关节定义数量不同
2. **buildJoints()**: 关节配置 + CAN 节点映射不同
3. **ros2_control 接口**: 声明的关节数不同
4. **控制器配置**: 关节列表不同
5. **Launch 文件**: 加载的控制器不同
6. **关节方向**: 安装方向不同（ec: +1.0, v3: -1.0）

与机械臂无关的代码（驱动、算法、感知、SLAM）两分支完全一致。
